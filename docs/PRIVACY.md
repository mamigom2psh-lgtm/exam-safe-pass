# 개인정보 보호 정책 (DEMO 프로토타입)

| 항목 | 정책 | 구현 |
|---|---|---|
| 얼굴 이미지 | 서버로 전송·저장하지 않음 | 브라우저 Canvas에서만 처리, `toDataURL/toBlob` 미사용 (테스트로 확인) |
| 생체 임베딩 | 서버로 전송·저장하지 않음, 사용 후 0으로 덮어씀 | `embedding?.fill(0)`, DB 스키마에 관련 열 없음 (테스트) |
| 감사 로그 | 주민등록번호, 이미지, 특징 벡터, 긴 인코딩 데이터 기록 금지 | `verification_policy.redact_details`가 모든 `write_event`에 적용, 500자 제한 |
| 데이터 최소화 | 점수는 화면에만 표시 | 서버는 브라우저 점수를 인증 근거로 받지 않음 (400 거부) |
| 접근 권한 | 관리자 현황판은 서버에서 admin 권한 확인 | `_require_role("admin")`, 응시자 번호는 끝 3자리만 표시 |
| 세션 만료 | 키오스크 세션 180초, DEMO QR 만료·1회 사용 | 서버 강제 |
| 삭제 | 감사 이벤트는 `EXAM_SAFE_EVENT_RETENTION_DAYS`(기본 30일) 경과 시 서버 시작 때 삭제 | `purge_old_events` |
| 저장소 | 얼굴 사진·DB·임베딩은 Git 제외 | `.gitignore`의 `images/`, `*.sqlite3`, `*.embedding` 등, `tests/test_privacy.py` |

등록 사진(`images/`)은 로컬에만 두고 커밋하지 마세요. 저장소를 클론한 환경에서는 가상 사진을 직접 넣어야 얼굴 비교 시연이 가능합니다.
실제 응시자 정보나 실제 얼굴 사진을 사용하지 마세요. 참고: 작업 호스트가 만든 로컬 체크포인트 커밋에 사진이 포함되어 있을 수 있습니다(원격 `origin/main`에는 없음). 푸시 전에 `git log --all -- images`로 확인하고, 필요하면 해당 로컬 ref를 정리하세요.
