# 심사용 DEMO 점검표

각 항목은 **자동 테스트 여부**와 **실제 사람이 확인해야 하는 항목**을 구분합니다. 아직 수행하지 않은 항목은 빈 칸으로 둡니다.
자동 테스트: `python3 -m pytest tests/test_judge_mode.py -q`

## A. 배포 전 (자동 + 로컬)

- [ ] 자동: `tests/test_judge_mode.py` 전체 통과
- [ ] 자동: `python3 tools/git_privacy_audit.py` 가 0건 (개발 저장소)
- [ ] 로컬: `python3 tools/export_judge_repo.py <새 폴더> --git-init` 감사 통과, 폴더에 `images/`, `*.jpg`, `*.sqlite3`, `.env`, `.git` 이력(커밋 1개 초과) 없음
- [ ] 로컬: 내보낸 폴더에서 `EXAM_SAFE_JUDGE_MODE=1 EXAM_SAFE_JUDGE_PASSWORD=<12자 이상> EXAM_SAFE_DB=/tmp/j/db.sqlite3 EXAM_SAFE_PHOTO_DIR=/tmp/j/p PORT=8080 python3 server.py` 실행 후 `/healthz`, `/judge-login`

## B. 실제 브라우저 시연 (PC, 사람이 확인)

- [ ] `https://<주소>/kiosk` 접속 → 로그인 화면으로 이동
- [ ] 잘못된 비밀번호 → 오류 메시지, 5회 이상 반복 시 잠시 후 재시도 안내(429)
- [ ] 올바른 비밀번호 → 키오스크 + 「심사용 DEMO · 합성 프로필 · 실제 입실 불가」 배너
- [ ] 셀프 인증 → 2026-0012 입력 → 「카메라 없이 사전 설정 시뮬레이션 체험」 → 자동 발급 시연(DEMO) → QR 표시, 30초 카운트다운, 「실제 입실 불가」 문구
- [ ] QR 입실 처리 1회 성공, 같은 QR 재사용 시 거부
- [ ] 30초 경과 후 QR 거부
- [ ] 가상 코드 입력 경로(추가 정보 입력): 올바른 값은 통과, 다른 응시자 값·다른 급수는 거부
- [ ] `/demo-candidates`, `/api/admin/candidates` 접속 → 403(로그인 후에도 차단)
- [ ] 로그아웃 후 뒤로 가기 → 키오스크 API 호출 401, 로그인 화면 복귀
- [ ] (선택) 카메라 허용 시 얼굴 참고 분석 표시, 결과가 「인증 성공」으로 표시되지 않음

## C. 서버 재시작 (Render 대시보드 → Manual Deploy → Restart)

- [ ] 재시작 후 이전 세션으로 접속하면 로그인 화면으로 이동(임시 DB 초기화) 또는 세션 유지 — 어느 쪽이든 오류 500 없음
- [ ] 재시작 전 발급한 QR은 재시작 후에도 입실 불가
- [ ] 재시작 후 가상 응시자 5명 재생성(2026-0012~0016 각각 조회 가능)
- [ ] 잠들었다가(15분 무접속) 첫 접속 시 로딩 지연 후 정상 응답

## D. 스마트폰 화면 (실제 기기, 사람이 확인)

- [ ] 세로 모드에서 로그인 입력창·버튼이 잘리지 않음
- [ ] 키오스크 배너·단계 표시·QR이 가로 스크롤 없이 표시, 글씨 잘림 없음
- [ ] 「큰 글씨」·「고대비」 버튼 동작
- [ ] 입력 필드 포커스 시 확대/가림 없음, 한글 입력 정상
- [ ] 카메라 권한 거부 시 안내 메시지 + 재시도/감독관 확인 경로 표시(인증 성공으로 바뀌지 않음)
- [ ] QR 이 다른 기기 카메라로 읽히고 `DEMO-ONLY:` 토큰이 표시됨

## E. 보안 확인

- [ ] 로그인 없이 `curl https://<주소>/api/kiosk/status -X POST -d '{}'` → 401
- [ ] 로그인 없이 `curl https://<주소>/api/candidate-photo/x` → 401
- [ ] 응답 어디에도 비밀번호/해시/가상 코드 원문(로그인 전)이 없음
- [ ] Render Logs 에 비밀번호·얼굴 이미지·임베딩이 없음
